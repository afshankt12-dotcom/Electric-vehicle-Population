## 📌 Project Overview

This project focuses on analyzing Electric Vehicle (EV) population data using **Python** for data cleaning and **Power BI** for visualization.

The goal is to extract meaningful insights such as EV growth trends, top manufacturers, model distribution, and year-wise adoption.

---

## 📊 Tools & Technologies Used

* 🐍 Python (Pandas, NumPy)
* 📊 Power BI
* 📁 Excel
